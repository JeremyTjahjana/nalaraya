# Sumber konten pengenalan laboratorium

Diperiksa 30 September 2026. Materi siswa berada di lib/introduction.ts dan components/HazardLegend.tsx; sumber ini disimpan terpisah untuk laporan.

- [OSHA pictograms](https://www.osha.gov/hazcom/pictograms): referensi visual sembilan gambar resmi. Unduhan langsung OSHA menghasilkan 403, sehingga aset lokal menggunakan konversi SVG dari gambar UNECE yang tersedia melalui Wikimedia Commons.
- [Katalog SVG GHS](https://commons.wikimedia.org/wiki/Category:GHS_pictograms_(Vector_drawings)): berkas GHS-pictogram-explos, flamme, rondflam, bottle, acid, skull, exclam, silhouette, pollu. Sumber asli EPS UNECE; konversi oleh DrTorstenHenning, dilepas sebagai public domain. Metadata sumber tetap terdapat dalam SVG di public/ghs.
- [OSHA pictogram quick card](https://www.osha.gov/sites/default/files/publications/OSHA3491QuickCardPictogram.pdf): arti sembilan pictogram. Lingkungan termasuk GHS tetapi tidak wajib dalam cakupan OSHA HCS; website mengajarkan GHS, bukan kewajiban label Amerika Serikat.
- [UNECE GHS labels](https://unece.org/labels-ghs): sumber induk label GHS. Akses otomatis pada pemeriksaan ini menghasilkan 403; gambar diverifikasi melalui OSHA.
- [OSHA Hazard Communication](https://www.osha.gov/laws-regs/regulations/standardnumber/1910/1910.1200): klasifikasi bahan/campuran, label, serta lembar data keselamatan.
- [NIOSH School Chemistry Laboratory Safety Guide](https://www.cdc.gov/niosh/docs/2007-107/pdfs/2007-107.pdf): dasar keselamatan sekolah, APD, larangan pipet dengan mulut, sumber panas, label dan pengelolaan bahan.

Model merupakan ilustrasi bentuk fungsional alat umum, bukan CAD atau sertifikasi produk. Skala tampilan disesuaikan agar setiap alat dapat diamati; tidak untuk membandingkan ukuran absolut antaralat. Instruksi dasar tidak menggantikan prosedur guru, petunjuk pabrikan, dan SDS produk. Katalog peralatan sengaja tidak mengimpor inventaris titrasi.

Kuis: dua soal alat (labu ukur, propipet), dua pictogram (pengoksidasi, perbedaan tengkorak/tanda seru), satu penggunaan aman (label/SDS). Lulus minimal 4/5; tidak mengunci eksperimen.
